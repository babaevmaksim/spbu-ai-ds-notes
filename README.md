# 📚 Конспекты и материалы образовательной программы «Искусственный Интеллект и Наука о Данных»

Реализуется на базе Математико-механического факультета Санкт-Петербургского государственного университета.

Репозиторий содержит актуальные академические конспекты лекций, экзаменационные билеты и книги, сверстанные в системе $\LaTeX$.

## 🏛 О программе
Образовательная программа разработана в рамках гранта «ТОП-ИИ», который реализуется Аналитическим центром при Правительстве Российской Федерации совместно с Минцифры России в целях достижения результата «Обеспечено обучение студентов по образовательным программам высшего образования для топ-специалистов в сфере искусственного интеллекта» федерального проекта «Искусственный интеллект», входящего в состав национального проекта «Экономика данных и цифровая трансформация государства».

> *TOP DS / AI) (TOP Data Science / Artifical Intellegence) --- высшая категория подготовки специалистов и исследователей в области искусственного интеллекта и науки о данных в рамках федеральных программ Минцифры России*
